## Before you start

General guidance: quiet room, consistent mic distance, no added vowel after
consonants, no trailing breath. A syllable demonstration must sound like a
syllable ON PURPOSE — it is labelled as one in the app.

**Hold each one about a second**, steady pitch, comfortable speaking loudness.
No fade, no swell, no falling pitch at the end.

**A word first, then the sound.** Say the word under your breath to find the
vowel, then produce the sound alone. Do not record the word.

**One take per file.** Try a sound as often as you like, keep only the take
you are happy with. A file holding two or more sounds is refused by the prep
tool rather than imported.

**File names are the slug, exactly as written below** (`kit_vowel.m4a`). Any
format the recorder makes is fine: m4a, wav, aiff or mp3.

**Record in the order printed here.** Entry order follows
`docs/PHONEME_RECORDING_LIST.md`, because `tools/prep_phonemes.py` `--split`
names files BY THIS ORDER when it cuts one continuous take — recording in a
different order misnames every clip.

### The syllable frame

Syllable-demo frame: /ɑː/ (PALM/BATH) — frames written /ɑːpɑː/, /ɑːtɑː/ and so
on. It is this accent's own long open back unrounded vowel, present in the
entries file (`palm_bath_vowel`) and given to RP by the spec's BATH split;
being open and unrounded it masks nothing about the consonant's closure,
release or voicing, and it is the nearest RP counterpart to the nam manifest's
/ɑ/ frame.

## Casting and what to listen for

Cast a trained stage or period-drama speaker with a conservative, Gimson-era
RP — a classical theatre voice, not a contemporary British screen voice.
Measured, evenly weighted stresses, the precision carrying the accent.

Biggest booth risk: modern Standard British leaking in. Listen for SQUARE
flattening to a steady /ɛː/, any /t/ going to [ʔ], a fused yod in tune, tensed
happY /i/, or a fronted GOOSE [ʉː]. Any of those is a retake, not a note.

Second risk: rhoticity. NURSE, PALM/BATH, THOUGHT and the three centring
diphthongs must end with no r-colour at all — a speaker who also works
American will colour them without hearing it.

Ask the speaker not to perform 'plumminess'. The spec flags the marked
upper-class varieties as variable, not the target; the reference clips must
stay the neutral conservative centre.

## Handing them over

1. Put every file you recorded in one folder, each named by its slug.
2. Tell me the folder. The prep tool trims the silence, levels the takes
   against each other, checks each file is a real recording, and writes MP3.
3. The 37 already-covered sounds are copied from the Neutral American set into
   the same folder under their own slug names, so import sees one complete
   course.
4. You listen at `#audit` and mark each one Good or Bad. **Only the ones you
   mark Good ever reach a learner** — approval is exact to the dialect, voice
   and slug.
5. Nothing about the other courses changes. Approving Traditional RP leaves
   every other accent exactly as it was.

The commands, from the manifest:

```bash
python3 tools/prep_phonemes.py <folder> --manifest tools/phoneme_manifest_rp.json --out prepped/
python3 tools/import_phonemes.py prepped/ --dialect rp --voice reference --dry-run
```

SHARE RULE. Most of these sounds are the same in every course, so one take is
recorded and copied into each. That is NOT safe for every entry: where an
accent's own published spec names a departure, that accent records its own.
Each entry carries "take": "shared" or "accent-specific" — never reuse another
course's file for an accent-specific one.
