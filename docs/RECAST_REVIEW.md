# Sonnets Recast — content review checklist (beta gate)

Every recast stays beta-labelled until each box is checked by a human
reviewer (owner or dialect specialist). One row per sonnet per dialect.

For each recast confirm:

- [ ] **Meaning** — central meaning, imagery and emotional movement of the
      original are preserved (compare against the Plain Meaning view).
- [ ] **Authenticity** — the register sounds like a real speaker of the
      dialect; nothing reads as costume slang or stereotype.
- [ ] **Density** — dialect features season the text; no line exists just
      to carry slang.
- [ ] **Meter** — we claim NO strict iambic pentameter; if a future pass
      regularises meter, it must be reviewed line by line before the claim
      changes.
- [ ] **Stereotype check** — no class, regional or ethnic caricature;
      Australian ≠ outback cosplay, Standard British ≠ mockney.
- [ ] **Pronunciation** — any word chosen for dialect flavour is
      compatible with the course's taught sound system.
- [ ] **Labelling** — displayed as "Creative dialect adaptation", never as
      a translation or an accent performance.

Pilot inventory to review: Sonnets 18, 29, 73, 116, 130 × (Plain Meaning +
NAM, Standard British, AUS recasts) = 5 summaries + 15 adaptations.
Traditional RP intentionally offers Original + Plain Meaning only.
